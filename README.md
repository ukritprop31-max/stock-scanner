# สแกนหุ้น RSI-based MA (เวอร์ชันคลาวด์)

สแกนหุ้นอัตโนมัติวันละ 4 รอบบน GitHub Actions (10:15, 18:20, 21:30 และ 04:50 น. เวลาไทย, จันทร์–ศุกร์)
แล้วเผยแพร่หน้าเว็บผ่าน GitHub Pages ให้เปิดได้จากมือถือทุกที่

- `scan.py` — ดึงราคาจาก Yahoo Finance, คำนวณ EMA 12–800, RSI 14, RSI-based MA (SMA 14), New low/New high 52 สัปดาห์
- `scanner_core.py` — สูตรคำนวณ (ชุดเดียวกับเวอร์ชันบนคอม)
- `site/` — หน้าเว็บ กรองเงื่อนไขในเบราว์เซอร์
- `thai_dr_list.json` — รายชื่อ DR ในตลาดหุ้นไทยกับหุ้นแม่ (ดึงจาก set.or.th วันที่ 8 พ.ย. 2026 — DR ใหม่ต้องอัปเดตไฟล์นี้)
- อยากสแกนทันที: แท็บ Actions → "สแกนหุ้นรายวัน" → Run workflow
